Chatbox

A simple and interactive Chatbox application built with React.
This project was created to practice React concepts such as components, state management, event handling, conditional rendering, and local storage.

Features
>Send and display chat messages
>Responds to messages like "Hi" and "Hello"
>Press Enter to send a message
>Prevents sending empty messages
>Clear chat messages
>Saves chat messages using Local Storage
>Dark Mode
>Typing indicator while the chatbot is replying

Technologies Used
>React.js
>JavaScript
>HTML
>CSS
>Vite
>Local Storage
