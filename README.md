Chatbox

A simple and interactive Chatbox application built with React.
This project was created to practice React concepts such as components, state management, event handling, conditional rendering, and local storage.

Features
1.Send and display chat messages
2.Responds to messages like "Hi" and "Hello"
3.Press Enter to send a message
4.Prevents sending empty messages
5.Clear chat messages
6.Saves chat messages using Local Storage
7.Dark Mode
8.Typing indicator while the chatbot is replying

Technologies Used
1.React.js
2.JavaScript
3.HTML
4.CSS
5.Vite
6.Local Storage
