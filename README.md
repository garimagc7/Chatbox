# Chatbox

A simple and interactive Chatbox application built with React.
This project was created to practice React concepts such as components, state management, event handling, conditional rendering, and local storage.

## Features

- Send messages
- Chatbot replies to messages
- Press Enter to send messages
- Prevents empty messages
- Dark mode
- Chat messages saved using Local Storage
- Typing indicator
- Clear chat button

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
